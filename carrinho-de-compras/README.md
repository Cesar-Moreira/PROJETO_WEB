# Carrinho de Compras

## Sobre o projeto
Página de loja virtual simples, com lista de produtos e carrinho de compras interativo. O usuário adiciona e remove itens, acompanha o valor total e mantém o carrinho salvo no navegador.

## Funcionalidades
- Listagem de produtos com nome e preço
- Filtro de produtos por faixa de preço (todos, até R$ 50 e acima de R$ 50)
- Adição de produtos ao carrinho com controle de quantidade
- Remoção de itens do carrinho
- Cálculo automático do valor total
- Limpeza do carrinho com confirmação
- Carrinho mantido ao recarregar a página (armazenamento local do navegador)

## Tecnologias utilizadas
- HTML
- CSS
- JavaScript (DOM e localStorage)
- Git
- GitHub

## Estrutura do projeto
- `Index.html`: estrutura da página
- `Css.css`: estilos da página
- `JavaScript.js`: lógica dos produtos, filtro e carrinho
- `Link para o vídeo de explicação.txt`: link do vídeo que explica o projeto
- `.gitignore`: arquivos que não devem ser enviados ao GitHub

## Como executar
1. Clone o repositório.
2. Acesse a pasta `carrinho-de-compras`.
3. Abra o arquivo `Index.html` no navegador.

Não é necessário instalar nenhuma dependência.
