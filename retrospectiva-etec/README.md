# Retrospectiva Etec

## Sobre o projeto
Site que reúne a retrospectiva dos três anos do curso de Desenvolvimento de Sistemas na Etec, com um relato sobre as matérias de cada ano e uma página de apresentação pessoal.

## Funcionalidades
- Página inicial com navegação para cada ano do curso
- Páginas do 1º, 2º e 3º ano com o relato de cada matéria
- Página pessoal com foto, apresentação, especialidades e contato
- Links de navegação para voltar à página inicial

## Tecnologias utilizadas
- HTML
- CSS
- Git
- GitHub

## Estrutura do projeto
- `paginas/`: páginas HTML do site e a folha de estilo (`style.css`)
  - `Index.html`: página inicial
  - `1º ano.html`, `2º ano.html`, `3º ano.html`: relato de cada ano
  - `Pessoal.html`: apresentação pessoal
- `Images/`: imagens utilizadas no site (`Foto.jpeg`)
- `.gitignore`: arquivos que não devem ser enviados ao GitHub

## Como executar
1. Clone o repositório.
2. Acesse a pasta `retrospectiva-etec/paginas`.
3. Abra o arquivo `Index.html` no navegador.

Não é necessário instalar nenhuma dependência.
