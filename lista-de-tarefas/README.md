# Lista de Tarefas

## Sobre o projeto
Aplicação web para organização de tarefas pessoais, em que cada tarefa é registrada com uma data e pode ser marcada como concluída ou removida.

## Funcionalidades
- Cadastro de tarefas com descrição e data
- Validação dos campos (preenchimento obrigatório e tamanho do texto entre 3 e 50 caracteres)
- Seleção de data pelo calendário (digitação manual bloqueada)
- Marcação de tarefa como concluída
- Remoção de tarefas
- Contador com o total de tarefas

> As tarefas ficam apenas na memória da página: ao recarregar, a lista é reiniciada.

## Tecnologias utilizadas
- HTML
- CSS
- JavaScript
- Git
- GitHub

## Estrutura do projeto
- `Lista.html`: estrutura da página e lógica em JavaScript
- `CSS/Css.css`: estilos da página
- `.gitignore`: arquivos que não devem ser enviados ao GitHub

## Como executar
1. Clone o repositório.
2. Acesse a pasta `lista-de-tarefas`.
3. Abra o arquivo `Lista.html` no navegador.

Não é necessário instalar nenhuma dependência.
