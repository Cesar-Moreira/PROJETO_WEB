# Portfólio de Projetos Web

Coletânea de projetos de desenvolvimento web criados durante o curso de Desenvolvimento de Sistemas, organizados por pasta e documentados individualmente. Cada projeto possui seu próprio README com funcionalidades, tecnologias e instruções de execução.

## Projetos

| Projeto | Descrição | Tecnologias |
|---|---|---|
| [carrinho-de-compras](carrinho-de-compras/) | Loja virtual simples com filtro de produtos e carrinho salvo no navegador | HTML, CSS, JavaScript |
| [lista-de-tarefas](lista-de-tarefas/) | Organização de tarefas com data, validação e conclusão | HTML, CSS, JavaScript |
| [retrospectiva-etec](retrospectiva-etec/) | Site com a retrospectiva dos três anos do curso e página pessoal | HTML, CSS |
| [sistema-analise-escolar](sistema-analise-escolar/) | Relatório estatístico do desempenho de uma turma a partir das notas | PHP, HTML, CSS |
| [crud_mundo](crud_mundo/) | Sistema completo de gerenciamento de continentes, países, cidades e governantes, com login e logs | PHP, MySQL, JavaScript, HTML, CSS |

## Tecnologias utilizadas
- HTML
- CSS
- JavaScript
- PHP
- MySQL
- Git
- GitHub

## Estrutura do repositório
```
portfolio-projetos-web/
├── carrinho-de-compras/
├── crud_mundo/
├── lista-de-tarefas/
├── retrospectiva-etec/
├── sistema-analise-escolar/
├── README.md
└── .gitignore
```

## Como executar
1. Clone o repositório.
2. Acesse a pasta do projeto desejado.
3. Siga as instruções do README da pasta. Os projetos em HTML abrem direto no navegador; os projetos em PHP precisam de um servidor local (como o XAMPP).
